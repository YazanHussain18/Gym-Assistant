# Gym Assistant V6 — Clean Start
New-device flow now starts with zero preloaded user data.

Onboarding:
1. Name, height, weight, primary goal, goal notes.
2. User enters Sunday–Saturday routine manually.
3. User adds exercises for each unique session with sets, rep range, optional target weight, and body area.
4. Review and create plan.

Smart Coach:
- Builds today's session from the user's own routine.
- Uses energy, sleep, soreness, pain, body location, recent sport, and workload/travel.
- Uses recent set/reps/RIR trends for progression.
- Can reduce volume/load or skip affected exercises.
- Tracks weigh-ins, exercise trends, and 7-day muscle coverage.

Plan tab allows full routine and workout editing after setup.
Reset returns the app to the clean first-run onboarding state.
